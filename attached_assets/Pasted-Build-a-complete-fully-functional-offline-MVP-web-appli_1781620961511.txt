Build a **complete, fully functional, offline MVP web application** called **Client Engagement Analyzer**.

This is a university project and the objective is to create a working end-to-end system that analyzes client conversations from audio recordings and generates actionable engagement insights.

## CRITICAL REQUIREMENTS

* This is NOT a UI prototype.
* Do NOT use placeholder data.
* Do NOT generate mock reports.
* Do NOT hardcode percentages.
* Do NOT simulate transcripts.
* Do NOT use any paid APIs or cloud services.
* The entire application must run locally on a standard development machine.
* Every result displayed in the frontend must originate from the uploaded or recorded audio.

Generate all frontend and backend code, folder structure, dependencies, setup instructions, and documentation required to run the project locally.
